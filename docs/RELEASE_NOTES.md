# Kontact++ Release Notes

## Version 1.0.0-rc01
Welcome to Kontact++. Manage contacts, recent calls and relationship details in one privacy-first phone experience. Get local connection insights and use optional AI assistance only when you choose.

### Key Features
- **Private Dialer**: Modern keypad and call history with local processing.
- **Relationship Assistant**: Keep private notes, track important dates, and set follow-up reminders.
- **Connection Insights**: On-device suggestions to help you stay in touch.
- **Optional AI**: Smart drafting assistance with full transparency and payload preview.
- **Privacy Center**: Clear controls over your data and permissions.
